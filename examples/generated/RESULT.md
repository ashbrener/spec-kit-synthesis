# Phase 1 result — the engine, proven end-to-end

`speckit-linear-architecture.generated.html` in this folder was **generated by
the pipeline**, not hand-written. It is the atlas output for the
spec-kit→Linear bridge, produced from that project's three real feature specs.
(The hand-written north-star it targets lives at
`../speckit-linear-architecture.html`.)

## How it was produced

```
specs/ (001, 002, 003)
  └─ adapter_speckit.py            → 222 source-typed fragments
       └─ extract (3 parallel agents, one per feature)
            → 42 claims · 16 decisions · 13 open questions  (every locator real)
       └─ reconcile (in-session reasoning — the product)
            → 40 current-state claims; 2 supersessions demoted to evolution notes
              (branch-gate → drift-aware authority; install UUID-first → key-only)
       └─ compose → 11-section document model
       └─ verify.py (fail-closed gate) → PASS (0 violations)
       └─ render.py → interactive, themeable SVG storybook
```

## The faithfulness gates (the integrity bar in action)

Two gates, both required by the design (`DESIGN.md` §5–§6):

1. **`verify.py` — deterministic, fail-closed.** Every claim's provenance must
   resolve to a real fragment; every block must be grounded; every callout must
   have a body; the coverage note must be present. Code-enforced, model-independent.

2. **Codex cross-model review — adversarial human-in-the-loop.** Ran five rounds:

   | Round | Issues | Severity |
   |------:|:------:|:---------|
   | 1 | 10 | 6 high, 4 med |
   | 2 |  8 | 3 high, 5 med |
   | 3 |  4 | 2 major, 2 minor |
   | 4 |  2 | 0 high, 2 med |
   | 5 |  **0** | **VERDICT: faithful (0/0/0)** |

## What this proved

- **The atlas works.** The in-session agent reasoned three overlapping,
  evolving specs into one current-state architecture — collapsing two
  supersessions into history while keeping the body current — and a second model
  independently judged the result faithful.
- **Faithfulness is enforced, not hoped for.** Round 1 surfaced a structural
  hole (empty callouts passed the gate); the fix was to *harden the gate in code*
  (new check, regression test), so the class of error cannot recur — not just to
  patch the prose.
- **Atlas surfaces what humans miss.** The tool flagged two genuine
  contradictions *inside the source specs* — the recency-drift rule (governing
  requirement vs companion note) and the lifecycle-ladder ordering used for drift
  — as honest "Unspecified" notes rather than silently picking a side. That is
  the design's "a confident wrong doc is worse than none" principle paying off.

## Honest caveats

- The reconcile/compose for this run was authored in-session as a build script
  (`.atlas/build_full.py`, gitignored per the stateless principle); the
  reasoning was real, but Phase 1 proves the *pipeline and the gates*, not yet a
  push-button one-command UX. That ergonomics pass is follow-on work.
- "Faithful" means: no high- or medium-severity unsupported/contradicting
  claims, with every genuine gap and source-contradiction surfaced — judged by
  an adversarial reviewer. It does not mean the document is the only possible
  good atlas.
